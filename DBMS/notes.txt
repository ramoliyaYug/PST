DDL:
- create table -> creates a new table
- alter table -> modifies the table
- read table -> reads the data from the table
- truncate table -> deletes all the data from the table
- drop table -> deletes the table
- rename table -> renames the table

DQL:
- select -> reads the data from the table
- selection -> selects the data from the table
 - filters data according to specified conditions using clauses
   1.where(conditions):
- projection -> projects the data from the table

  - wrtie a query to display name and job : select name, job from employee
  - use of distinct
    displays unique records
    select distinct column_name from table_name
    select distinct job from employee
  - expression:
    
  - write query to display salary with 10% high
    select salary*1.1 from employee
  - write query to display salary with 10% low
    select salary*0.9 from employee
  - write query to display salary total salary of employee
    select salary+commission from employee (this is not correct if commission is null then total amount will be null)
    select salary+ifnull(commission,0) from employee
  - Alias:
    column as 'Alias Name'
  - write query to display annual salary
    select salary*12 as 'annual salary' from employee
    select salary*6 as 'Half Annual Salary' from employee
    select salary/30 as 'Daily Salary' from employee    


  - write query to display details of employee who are earning more than 1500
    select * from employee where salary>1500
  - write query to display details of employee who are working as a salesman
    select * from employee where job='salesman'
  - write query to display salary where the employee earn more than 20,000 annualy
    select ename, salary*12 as 'Annual Salary' from employee where salary*12>20000
  - write a query to display the name and hire date of employee who are hired after year 1981
    select ename, hiredate from employee where hiredate>'1981-12-31'
    select ename, hiredate from employee where hiredate>'1981-01-01' // hired in and after 1981


  - qualifier:
    - if you need to display all the column of the table along with the new column you need to use qualifier along with the table name
      [table_name.*,column_name]

  - write query to display all the all the details of the employee along with annual salary of the employee
    select employee.*, salary*12 as 'Annual Salary' from employee
    select employee.*, salary+ifnull(commission,0) as 'Total Salary' from employee
  
  - in the latest mysql you can do *,column_name so you do not need of qualifier
